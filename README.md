# 🌍 AI Travel & Tourism Recommendation System

An AI-powered Travel & Tourism Recommendation System designed to help users plan their trips efficiently. The application provides personalized destination recommendations, flight search, hotel information, car booking, and travel management through third-party API integration.

---

## 📌 Project Overview

This project is a full-stack web application developed using Angular for the frontend, Node.js & Express.js for the backend, and MySQL for database management. It integrates multiple third-party APIs to provide real-time travel-related information and AI-based recommendations.

---

## 🚀 Features

- 🔐 User Registration & Login
- 🤖 AI-based Travel Recommendations
- ✈️ Flight Search
- 🏨 Hotel Recommendations
- 🚗 Car Booking
- 🗺️ Destination Suggestions
- 📍 Interactive Maps
- 📱 Responsive User Interface
- 🗄️ MySQL Database Integration
- 🔗 Third-Party API Integration

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/shadab3105-coder/AI-Travel-and-Tourism-Recommendation-System.git
```

### Frontend

```bash
cd angular
npm install
ng serve
```

Runs on:

```
http://localhost:4200
```

---

### Backend

```bash
cd backend_latest
npm install
node server.js
```

---

### Database

1. Create a MySQL Database.
2. Import

```
tavels_1.sql
```

3. Update your database credentials inside the `.env` file.
